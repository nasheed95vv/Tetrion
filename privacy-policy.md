# Политика конфиденциальности для Google Play

Полный текст: `../../PRIVACY_POLICY.md`, HTML для публикации: `../../privacy-policy.html`.

В Play Console (Policy → App content → Privacy policy) нужно указать **публичный URL**, по которому открывается `privacy-policy.html` без входа и без скачивания (например, GitHub Pages, сайт разработчика). Локальный файл в проекте ссылкой не является.

URL: [ЗАПОЛНИТЬ после размещения] — также вписать в `app/src/main/res/values/config.xml` → `privacy_policy_url`.
